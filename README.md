
# Pothole Detection and Alert System

## Introduction
This project detects potholes in road images using
Computer Vision and YOLOv8 Nano.

## Features
- Upload road images
- Detect potholes
- Display bounding boxes
- Show confidence scores
- Count detected potholes
- Generate warning alerts

## Technologies
- Python
- YOLOv8
- OpenCV
- Streamlit

## Model
YOLOv8 Nano
